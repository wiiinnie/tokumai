01 · How it works

Two things that never meet

Your identity and your questions. The app talks to the tokumai server only through the Nym mixnet (Sphinx packets, five hops, cover traffic); the server has no public address at all. Others hide what you say. We make sure it can never be traced back to you.

No real-world identity

No email, no phone number, no login. Your account is a recovery phrase that only you hold.

Unlinkable payments

Top up once, then spend blind tokens. Even if you pay by card, nobody can connect your payment to a single prompt. That includes us.

Untraceable prompts

Every request travels through the Nym mixnet. Our servers never see an IP address. No prompt can be traced back to a person.

No profile of you

Without an identity, an IP or a traceable payment, there is nothing to build a profile on. Your questions never add up to a picture of you as a real person.

Text with Gemini or GPT, pictures with Imagen. A prompt costs a few hundredths of a cent, a 4K picture around fifteen cents; the price is shown before you send.

04 · Verify a download

Check the file before you open it

The builds are not signed by a store, so the checksum is your proof that the file is the one we published. Copy the line for your system into a terminal — it prints OK (macOS, Linux) or True (Windows) when the download matches.

macOS
Terminal · file in ~/Downloads
cd ~/Downloads && echo "{{SHA_MACOS}}  {{FILE_MACOS}}" | shasum -a 256 -c
expect {{FILE_MACOS}}: OK
🐧 Linux
Shell · file in ~/Downloads
cd ~/Downloads && echo "{{SHA_DEB}}  {{FILE_DEB}}" | sha256sum -c
expect {{FILE_DEB}}: OK
Got the AppImage instead? Same command with {{FILE_APPIMAGE}} and its sha256 from the download card.
⊞ Windows
PowerShell · file in Downloads
(Get-FileHash "$env:USERPROFILE\Downloads\{{FILE_WINDOWS}}" -Algorithm SHA256).Hash -eq "{{SHA_WINDOWS}}"
expect True
🤖 Android
Termux · file in Download
cd ~/storage/downloads && echo "{{SHA_ANDROID}}  {{FILE_ANDROID}}" | sha256sum -c
expect {{FILE_ANDROID}}: OK
No Termux? Check the .apk on a computer with the macOS or Linux line above, then copy it to the phone.

Mismatch or "FAILED"? Don't open the file — download it again from this page, and if it still differs, tell us. The sha256 values above are also printed on each download card.
