# Provider marks

Third-party trademarks, kept here so the model picker can name what it is actually calling.
They are **not** ours: do not recolour them, do not redraw them, and do not put them anywhere
that suggests endorsement or partnership. Naming a model in text ("Gemini 3.1 Flash-Lite") is
descriptive use and needs no permission; a logo inside our own product UI is a different
question, and Google in particular expects to be asked. Treat every file here as optional —
the picker falls back to the provider's name as text when a mark is missing, so nothing
breaks if one has to come out again.

monochrome variant, replace it — a 19 px mark drawn from a 512 px PNG is fine, but vector is
better, and a single-colour version would sit more quietly on our dark ground.
