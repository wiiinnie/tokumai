Tutorial

      
      

      
Typing

      

      

      

      
Everything you send is routed to hide who you are. The defaults give you the most privacy. You can trade some of it for more speed, or dial things back to save battery — all optional and reversible. Each slider is stepless; the live value reads under it.

      

        
Cover traffic

        
        
save batterybalancedmost cover

        

        
› What this does
          
A constant stream of decoy (“cover”) packets so your real messages hide inside steady, uniform traffic. Shown as the bandwidth it constantly uses — more cover hides you better but uses more data and battery; less runs cooler but thins the decoy stream. (Nym’s loop_cover_traffic rate)

        

      

      

        
Packet mixing delay

        
        
0 ms · fastest100 ms200 ms · max

        

        
› What this does
          
The random hold each packet waits at every hop before moving on — a Poisson delay (so it’s in ms, not a rate). This reshuffling of packet order is the anonymity: more delay mixes you with more people’s traffic, less delay is faster. The biggest lever on mixnet latency. Default 15 ms. (Nym’s average_packet_delay)

        

      

      

        
Sending rate

        
        
0.1 Mbps · lean1 Mbps · default2 Mbps · fastest

        

        
› What this does
          
The constant rate your real packets leave the device — a throughput dial, so it reads in Mbps (this is exactly NymVPN’s “traffic rate”). Higher = big files and long messages upload quicker, at more constant bandwidth. “Pipelining” below is a separate on/off. (Nym’s message_sending rate)

        

      

      
      
      
      

      

      

      
Send the model less of the transcript when it isn’t needed — fewer tokens leave this device, so each message costs less. The topic decision is made locally, never by an extra model call.

      

        
Conversation memory

        
How many recent exchanges are always sent as context — higher means better continuity but more tokens per message. Older related turns are still added on top.

        
        
last 2last 4last 8everything

      

      

        
Reasoning depth

        
How long the model “thinks” before it answers. Thinking bills as output tokens, so less = faster and cheaper; more = better on hard problems. “Off” is snappiest for chat and simple tasks. Applies to Gemini models.

        
        
Off · fastestLowBalancedDeep

      

      

        
Image size

        
Resolution of generated pictures (Nano Banana 2). Bigger pictures cost more tokens and take longer through the mixnet — 4K is several megabytes and a few minutes. 1K is the default.
Nano Banana 2 Lite draws 512 / 1K only: 2K or 4K on Lite is drawn — and billed — as 1K, and the answer says so.

        
        
512 · ×0.671K2K · ×1.54K · ×2.25

Image upload size

        
One dial for resolution + quality before upload. The mixnet path is ~50 KB/s, so upload time ∝ file size. Vision models tile at ~768–1024 px, so smaller barely affects what the model sees.

Mixnet ping

        
Times a tiny round-trip to the server with NO model call — the pure mixnet latency. Use it to see what the “Response speed” slider in Network & Privacy actually changes (change it, then ping a few times per setting).
